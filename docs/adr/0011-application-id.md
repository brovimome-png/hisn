# ADR-0011: اسم الحزمة (`Application ID`)

- **الحالة:** **مقبول** — قرار منفَّذ بتفويض المالك في 2026-11-01
- **التاريخ:** 2026-11-01
- **يخصّ:** `applicationId`، و`namespace`، ومعرّفات الوحدات، وتحديثات التطبيق مدى الحياة

## السياق

`Application ID` هو هوية التطبيق على الجهاز وفي المتاجر ومصادر التحديث. **لا يمكن تغييره بعد أول إصدار
منشور** دون أن يصبح تطبيقًا آخر لا يُحدِّث القديم — أي أن هذا قرار يُتخذ مرة واحدة. ويشترطه
[ADR-0006](0006-distribution.md): F-Droid يتطلّب معرّفًا فريدًا ومستقرًا للبناء من المصدر.

القاعدة المعتادة (نطاق معكوس) تفترض ملكية نطاق. **المشروع لا يملك نطاقًا**، واختيار نطاق لم يُشترَ
يخاطر بالتصادم مع مالكه الحقيقي.

## الخيارات

| المعرّف | ملاحظات |
|---|---|
| **`io.github.brovimome.hisn` — المعتمد** | فضاء أسماء نملكه فعلًا (حساب GitHub)، فريد، لا يدّعي نطاقًا، و`io.github.*` نمط متعارف عليه للمشاريع المفتوحة |
| `com.hisn.blocker` | يدّعي `hisn.com` ولا نملكه؛ تصادم محتمل مع مالكه، ويصعب تبريره لاحقًا |
| `app.hisn.blocker` | نفس المشكلة: `hisn.app` نطاق حقيقي مملوك لغيرنا |
| `dev.hisn.hisn` | نفس المشكلة بصيغة أخرى |
| `org.hisn.blocker` | يوحي بمنظمة غير موجودة، وقد يُقرأ كانتحال |

## القرار

- `applicationId = "io.github.brovimome.hisn"`
- `namespace = "io.github.brovimome.hisn"`، والوحدات `io.github.brovimome.hisn.core.dns` وهكذا.
- اسم العرض للمستخدم يبقى «حِصن» بالعربية، و«Hisn» بالإنجليزية — **اسم العرض مستقل عن المعرّف**.

## السبب

1. **فضاء أسماء مملوك فعلًا:** الحساب `brovimome-png` على GitHub يخصّ المالك، فلا أحد يستطيع المطالبة
   به غدًا، خلافًا لنطاق غير مشترى.
2. **بلا ادّعاء ملكية:** لا نستخدم اسم منتج آخر ولا نطاق غيره، وهذا شرط
   [AGENTS §8](../../AGENTS.md).
3. **جاهز لـ F-Droid:** معرّف فريد ومستقر يمكن بناؤه من المصدر، مع تسجيله في الاستعلام الوصفي.

## العواقب

- **إيجابي:** لا خطر تصادم، ولا حاجة لشراء نطاق قبل أول إصدار.
- **سلبي:** المعرّف يحمل اسم حساب GitHub؛ إن تغيّر اسم الحساب لاحقًا سيبدو غير متسق (لكن **لا يتغيّر
  المعرّف** مهما حدث، لأن تغييره يكسر التحديثات).
- **قيد:** الانتقال إلى نطاق مملوك لاحقًا **غير ممكن** بنفس المعرّف؛ أي تغيير يعني تطبيقًا جديدًا
  وتطوّعًا من المستخدمين بالانتقال. القرار يُعاد فتحه فقط بورقة ADR جديدة.

## ما لم يُتحقق منه

- **لم يُختبر** بناء فعلي بهذا المعرّف (لا مشروع Gradle بعد).
- **لم يُتحقق** من عدم وجود تطبيق منشور آخر بهذا المعرّف على F-Droid — يُفحص في المرحلة 7 قبل أول نشر.
- التسجيل في استعلام F-Droid الوصفي (`fdroiddata`) **لم يُجرَّب**.
