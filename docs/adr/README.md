# سجلّ القرارات المعمارية (ADR)

كل قرار كبير له ورقة واحدة: السياق، الخيارات، القرار المقترح، السبب، العواقب، وما لم يُتحقق منه.
الحالة تكون واحدة من: **مقترح** (بانتظار موافقة المالك) / **مقبول** / **مرفوض** / **مُستبدَل بورقة أخرى**.

| # | القرار | الحالة | الخلاصة |
|---|---|---|---|
| [0001](0001-stack.md) | اللغة والإطار | مقترح | Kotlin + Jetpack Compose، أندرويد أصلي، `minSdk 26` |
| [0002](0002-blocking-engine.md) | محرك الحجب | مقترح | `VpnService` محلي يعترض DNS، بلا روت وبلا MITM |
| [0003](0003-storage.md) | حفظ البيانات | مقترح | DataStore للإعدادات + ملفات للقوائم + عدّادات صغيرة، بلا Room الآن |
| [0004](0004-filter-lists.md) | القوائم وتراخيصها | مقترح | `hosts` + مجموعة فرعية من Adblock Plus، مع تسجيل ترخيص كل قائمة |
| [0005](0005-youtube-in-app-ads.md) | يوتيوب داخل التطبيق | **مقبول** | لا وعد بحجبه؛ متصفح + بديل مشغّل لاحقًا؛ لا ترقيع تطبيقات |
| [0006](0006-distribution.md) | التوزيع | **مقبول** | GitHub Releases + F-Droid، لا Google Play |
| [0007](0007-localization.md) | التعريب | مقترح | العربية في `values/` افتراضيًا، تبديل داخل التطبيق، فحص اتساق في CI |
| [0008](0008-license.md) | الرخصة | **مقبول** | GPL-3.0، وملف `LICENSE` في المستودع |
| [0009](0009-testing-and-ci.md) | الاختبارات وCI | مقترح | JVM في كل PR + lint/بناء + محاكي في مهمة منفصلة |
| [0010](0010-min-sdk.md) | أقل إصدار أندرويد | **مقبول** | `minSdk = 26` (أندرويد 8.0)؛ `targetSdk` يُثبَّت في المرحلة 1 |
| [0011](0011-application-id.md) | اسم الحزمة | **مقبول** | `io.github.brovimome.hisn` — فضاء أسماء مملوك فعلًا، بلا ادّعاء نطاق |
